# Repomix 使用场景和应用案例

## 主要使用场景

### 1. AI 代码审查和分析

#### 1.1 全面的代码库审查
**使用方式**:
```bash
# 基础代码打包
repomix

# 包含 Git 历史的高级打包
repomix --include-logs --include-diffs

# 压缩模式，减少 Token 使用
repomix --compress
```

**AI 提示词示例**:
```
这是一个完整的代码库打包文件。请进行全面的代码审查：
1. 分析整体架构和代码结构
2. 识别潜在的安全漏洞
3. 评估代码质量和可维护性
4. 提供重构建议
5. 检查设计模式的使用
```

#### 1.2 架构分析
**应用场景**: 理解大型项目的架构设计

**分析维度**:
- 模块划分和依赖关系
- 设计模式应用
- 代码组织结构
- 技术栈选择
- 性能优化策略

**AI 提示词示例**:
```

1. 识别常见的安全漏洞（OWASP Top 10）

3. 评估认证和授权机制
4. 分析数据加密和保护
5. 检查第三方依赖的安全性
6. 提供具体的修复建议
```

## 最佳实践建议

### 11. 使用策略

#### 11.1 文件选择策略
```bash
# 只分析核心代码
repomix --include "src/**/*.ts" --ignore "**/*.test.ts"

# 分析特定模块
repomix --include "src/modules/auth/**"

# 排除构建产物
repomix --ignore "dist/**,build/**,node_modules/**"
```

#### 11.2 输出格式选择
- **XML**: AI 处理、结构化分析
- **Markdown**: 人工阅读、文档生成
- **JSON**: 程序化处理、数据分析
- **Plain**: 简单查看、快速检查

#### 11.3 安全检查配置
```bash
# 严格安全检查
repomix --security-check --no-default-patterns

# 自定义安全规则
repomix --security-check --ignore "config/secrets.json"
```

### 12. 性能优化

#### 12.1 大型项目处理
```bash
# 分模块处理
repomix --include "src/core/**" --output core-analysis.xml
repomix --include "src/ui/**" --output ui-analysis.xml

# 压缩模式减少 Token
repomix --compress --remove-comments --remove-empty-lines
```

#### 12.2 内存使用优化
- 使用流式处理大文件
- 分批处理大量文件
- 监控内存使用情况
- 及时清理临时数据
