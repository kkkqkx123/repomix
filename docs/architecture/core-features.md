# Repomix 核心功能分析

## 项目概述

Repomix 是一个强大的代码库打包工具，专门设计用于将代码库内容打包成适合 AI 处理的单一文件格式。它提供了丰富的功能集，支持多种输出格式、安全检查和 AI 工具集成。

## 核心功能模块

### 1. 代码打包引擎 (Core Packager)
**位置**: `src/core/packager.ts`

主要功能：
- **文件收集与处理**: 递归扫描目录，收集符合规则的文件
- **模式匹配**: 支持 glob 模式匹配文件选择
- **路径扁平化**: 可选的路径扁平化功能，简化文件结构
- **文件处理**: 移除注释、空行，进行代码压缩
- **安全检查**: 扫描敏感信息，如 API 密钥和密码
- **Git 集成**: 获取 Git diff 和提交历史
- **多格式输出**: 支持 XML、Markdown、JSON、Plain 文本格式

### 2. 命令行界面 (CLI)
**位置**: `src/cli/`

主要功能：
- **丰富的命令选项**: 50+ 个命令行参数支持
- **智能语义映射**: 提供命令建议和自动补全
- **多种运行模式**: 本地目录、远程仓库、标准输入输出
- **进度反馈**: 实时显示处理进度
- **配置管理**: 支持配置文件和命令行参数组合

### 3. 文件处理系统
**位置**: `src/core/file/`

主要功能：
- **智能文件过滤**: 基于 .gitignore 和自定义规则
- **文件搜索**: 递归目录扫描和模式匹配
- **文件处理**: 内容清理、注释移除、代码压缩
- **路径排序**: 智能文件路径排序和分组
- **二进制文件处理**: 安全处理二进制文件和大型文件

### 4. 安全检查系统
**位置**: `src/core/security/`

主要功能：
- **敏感信息检测**: 扫描 API 密钥、密码、令牌等
- **文件安全验证**: 验证文件内容安全性
- **Git 安全检查**: 检查 Git 历史和差异中的敏感信息
- **可配置安全规则**: 支持自定义安全检测模式

### 5. Git 集成
**位置**: `src/core/git/`

主要功能：
- **Diff 获取**: 获取工作区和暂存区的变更
- **提交历史**: 获取最近的提交记录
- **变更频率分析**: 基于 Git 历史分析文件变更频率
- **分支支持**: 支持特定分支、标签或提交的处理

### 6. 输出生成系统
**位置**: `src/core/output/`

主要功能：
- **多格式支持**: XML、Markdown、JSON、Plain 文本
- **结构化输出**: 包含文件树、元数据、文件内容
- **自定义模板**: 支持输出模板和格式自定义
- **压缩优化**: 可选的代码压缩和优化
- **剪贴板集成**: 自动复制输出到系统剪贴板

### 7. MCP 服务器集成
**位置**: `src/mcp/`

主要功能：
- **Model Context Protocol**: 作为 MCP 服务器运行
- **AI 工具集成**: 提供 AI 友好的代码库分析工具
- **远程仓库支持**: 支持 GitHub 等远程仓库分析
- **文件系统工具**: 提供文件读取和目录浏览功能
- **搜索工具**: 支持在打包输出中进行搜索

### 8. 度量和分析
**位置**: `src/core/metrics/`

主要功能：
- **Token 计数**: 精确的 Token 计数（支持多种编码）
- **文件统计**: 文件数量、字符数、行数统计
- **性能监控**: 内存使用和性能指标
- **代码复杂度**: 基于 Tree-sitter 的代码结构分析

## 技术架构特点

### 1. 模块化设计
- 清晰的模块分离和职责划分
- 依赖注入模式提高可测试性
- 插件化架构支持功能扩展

### 2. 高性能处理
- 流式处理大文件
- 并行文件处理
- 内存使用优化
- 增量处理支持

### 3. 安全优先
- 多层安全扫描
- 敏感信息自动检测
- 可配置的安全规则
- 安全处理二进制文件

### 4. AI 友好设计
- 结构化输出格式
- Token 优化压缩
- 上下文信息丰富
- 多种输出格式适配

### 5. 开发者体验
- 丰富的命令行选项
- 详细的进度反馈
- 配置文件支持

## 主要使用场景

1. **AI 代码审查**: 将代码库打包供 AI 进行全面的代码审查
2. **文档生成**: 基于代码库生成项目文档和 API 文档
3. **代码分析**: 进行代码质量评估和架构分析
4. **安全审计**: 检测代码中的安全漏洞和敏感信息
5. **知识提取**: 从代码库中提取业务逻辑和架构信息
6. **迁移辅助**: 协助代码库迁移和重构项目

## 扩展能力

- **自定义输出格式**: 支持添加新的输出格式
- **安全规则扩展**: 可添加自定义安全检测规则
- **文件处理插件**: 支持自定义文件处理逻辑
- **集成扩展**: 可与其他开发工具集成

Repomix 通过其强大的功能集和灵活的架构，为 AI 辅助开发提供了完整的代码库分析解决方案。
